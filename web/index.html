READING THIS MODEL

Architecture, made observable.

Start runs repeated bounded inference jobs. Pause freezes simulated time; Step advances it explicitly. Counters and tile states come from the SystemC process, not an animation.

Wall-clock pacing makes the model inspectable. It is not hardware throughput. Target latency depends on the declared clock, memory and compute assumptions.

This is a local architectural simulator, not a physical NPU device or a calibrated commercial NPU emulator. The dashboard uses no external assets or network services.
